# PhonePhotoCleanup
scripts and programs to clean up space on my phone for photos and videos



Future enhancements
we could take this much further. A version 2 could:
- Display photos grouped by year and month with counts and total size.
- Detect near-duplicate photos (same picture at different resolutions or slight edits), not just exact duplicates.
- Identify blurry photos using image analysis.
- Find screenshots, memes, and downloaded images separately.
- Show the largest 500 files with an interactive interface.
- Present a full-screen terminal UI (similar to `htop`) where you can navigate with the arrow keys, press Space to mark photos, and D to delete or M to move them.
That interactive version would feel much more like a professional file manager and could make cleaning up thousands of photos much faster.
